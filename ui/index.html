    Connection

      First time on a new laptop or drone build
      1. In MATLAB, with the project open, run enable_groundstation once. It adds the telemetry sender to PerceptionAndGuidance.slx. Guidance logic is not changed.
      2. Deploy as usual (Step_2_Deploy_PerceptionModel → Build, Deploy & Start).
      3. Open this app. Packets arrive as soon as the drone arms. No IP setup: the drone broadcasts on UDP 47800.
      4. If nothing arrives, click Allow on the firewall row above.
