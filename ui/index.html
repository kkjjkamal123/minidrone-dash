    You never need to open MATLAB: any button here starts it in the background (about 30-60 s the first time) and it stays ready.

    2 · Raspberry Pi

    4 · Fly

    Flight controller (safety controls)
    
            
    
              
    ARM, LAND and DISARM talk to PX4 on the Pixhawk over MAVLink,
                not through the Pi. Pick how this laptop reaches the Pixhawk.
    
              
    
                
                
                
              
    
              
    
              
    The RC transmitter stays the primary safety. This flight controller runs the
                MathWorks controller, which lands from the RC switch on channel 8, not from PX4's Land mode.
                LAND here asks PX4 to land and then watches the altitude: if the drone does not descend within
                3 s the bar turns red. Then use the RC land switch or DISARM. DISARM stops the motors at once,
                even in the air.

    Setting up a new drone build
    
            
    
              
      
                
    1. In MATLAB, with the project open, run enable_groundstation once. It adds the
                  telemetry sender next to lineGuidance in PerceptionAndGuidance.slx.
                  Guidance logic is not changed.
      2. 
                
    2. Deploy as usual: Step_2_Deploy_PerceptionModel, then Build, Deploy & Start.
      3. 
                
    3. Open this app. Data arrives as soon as the drone arms. The drone broadcasts on UDP 47800,
                  so no IP address needs to be entered anywhere.
      4. 
                
    4. If nothing arrives, use Allow on the firewall check (needs admin).
      5. 
              
    
              
    To remove the sender again: disable_groundstation.
